Entry for the [make.fun](https://make.fun/c/the-joke-about-the-demo-20261123-0112)
competition "The joke about the demo" ($50, 20 paid places).

`main.py` (Python 3.13, standard library only, no network) writes one
one-line joke about working beside AI coding agents to `/output/entry.txt`:

> Agent fixed the crash. It deleted the demo.
